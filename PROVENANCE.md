# Public snapshot provenance

This clean-history release was prepared from audited source commit
`4d548082dd1e` of the private research archive.

The source archive remains private because its earlier Git history contained a
credential that was later removed. That history is intentionally not connected
to this public repository. The current snapshot follows the inclusion and data
boundaries documented in [`PUBLIC.md`](PUBLIC.md) and [`DATA.md`](DATA.md).

Credential rotation remains required for any secret that appeared in the
private archive, even though that value is absent from this snapshot.
