# Public release boundary

This repository is a clean-history research snapshot intended for code review,
reproduction work, and collaboration.

The public tree contains implementation code, setup documentation, and compact
detector metrics. It excludes row-level research data, individual generations,
human-evaluation records, model weights, operational logs, manuscripts,
submission packages, and private archives.

The original workbench history remains private because an older commit
contained a credential that was later removed. No object from that history is
connected to this public Git history. Any credential that appeared in the
private archive must still be rotated.

Before adding new artifacts, verify data redistribution rights, remove personal
or infrastructure metadata, and run secret scanning.
